## 这个仓库是什么

这不是一个"自媒体素材库"，而是**每一篇笔记背后完整的数据分析流程**。

小红书上发出去的是结论，这里留下的是可复现的过程：

```
选题 → 定结论 → 取数 → 清洗 → 建模 → 可视化 → 成图发布 → 数据复盘
```

每篇笔记对应一个独立的数据分析项目。脚本开源、结果可复现、复盘数据公开。

## 出图设计系统

每篇笔记的 9 张图，全部由 `02-data/scripts/xhs_kit.py` 统一产出：

- 1080×1440 画布，正文区固定 y=200→1268，页脚固定
- 两个数据色（墨黑 / 朱红），中英同一套可变字体，靠字重分层级
- 图表用 PIL 手绘（不引 matplotlib），保证图上字体与全篇一致
- **每页出图自带溢出自检**：内容底部超过 1268 直接报警，避免出现半页空白

新增一篇内容时，只需写一个 `topicNN_make_images.py`，复用 kit 里的组件（数据块、条形图、点阵示意图、清单）。

## 数据复盘

全部笔记的表现记录在 [`04-tracker.csv`](./04-tracker.csv)。核心判定标准：

| 指标 | 合格线 | 含义 |
| --- | --- | --- |
| 点击率 | > 10% | 低于此说明封面/标题有问题，与内容质量无关 |
| 收藏率 | > 5% | 干货型内容的核心指标 |
| 收藏 / 点赞 | > 1 | 说明是"有用"而非"好看"，符合定位 |
| 涨粉率 | > 1% | 账号吸引力 |

判定后的动作：爆（>1 万曝光）→ 48h 内出续集吃掉流量；平 → 保留并加大配比；扑（<1000）→ 改封面标题重发一次，再扑就换选题。
