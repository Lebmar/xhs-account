# 数据目录

每个选题 = 一个独立的数据分析项目。

---

## 结构

```
02-data/
├── scripts/      分析脚本，每个选题一个文件
├── raw/          原始数据（gitignore，不入库）
└── results/      聚合后的统计结果（可入库）
```

## 命名规范

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 脚本 | `topic{编号}_{英文简述}.py` | `topic17_xhs_title_analysis.py` |
| 原始文件 | `topic{编号}_raw.{ext}` | `topic17_raw.jsonl` |
| 结果文件 | `topic{编号}_result.csv` | `topic17_result.csv` |

## 脚本要求

每个脚本开头必须写明：

```python
"""
选题 #17：爬了 1 万条小红书笔记，爆款标题长什么样
数据来源：小红书公开搜索页
采集时间：2026-10-XX
样本量：10xxx
结论：<一句话>
"""
```

结尾输出聚合结果到 `../results/topic{编号}_result.csv`。

## 依赖

```
pandas
numpy
matplotlib
requests / httpx
```

建议建独立虚拟环境，不要污染全局。

---

## 合规要求（必须遵守）

1. 抓取前检查目标站点 `robots.txt`
2. 控制请求频率，加延时，不做高频请求
3. **不采集、不存储任何个人身份信息**（昵称、ID、头像等一律丢弃或哈希化）
4. 仓库只提交脚本和聚合结果，`raw/` 已在 `.gitignore` 中
5. 笔记中涉及具体公司、个人一律匿名化
6. 数据仅用于统计分析，不做任何商业用途
