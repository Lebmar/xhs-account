# 成图归档

每篇笔记的 9 张成品图，按选题编号归档。

```
03-output/
├── topic17-爆款标题实测/
│   ├── 01-封面.png
│   ├── 02-问题.png
│   └── ...
└── topic16-PISA成绩预测/
```

## 命名

`{两位序号}-{内容}.png`，序号对应 9 图结构：

| 序号 | 内容 |
| --- | --- |
| 01 | 封面 |
| 02 | 提出问题 |
| 03 | 数据从哪来 |
| 04–07 | 数据图 |
| 08 | 最终结论 |
| 09 | 互动引导 |

## 出图规范

- 尺寸：竖版 3:4，1080 × 1440
- 配色严格按 [内容规范](../docs/内容规范.md)
- 每张图配标题 + 坐标轴标注 + 数据来源脚注
- 图表全部自己用 matplotlib / Plotly 出，不截图他人内容
