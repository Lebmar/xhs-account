# 小红书账号启动方案

> 定位：**用真实数据回答大学生靠感觉争论的问题**
> 平台：小红书（主）→ 公众号 / GitHub（沉淀作品集）
> 制定日期：2026-10-09

---

## 一、为什么是这个定位

### 交叉点稀缺性
小红书上做「数据实测」的大学生博主极少。会跑数据的人不愿意写通俗内容，想写通俗内容的人不会跑数据。你（港科广数据科学大三，Python / SQL / R / 统计 / 建模全套）正好站在中间。

### 这个定位的三重收益
1. **内容即作品集**：每篇笔记背后是一个真实数据项目（取数 → 清洗 → 建模 → 可视化），直接补上你简历里最缺的一段；而且自带传播数据，可量化。
2. **和主线完全同向**：你在找实习，做「实习 JD 分析」的过程本身就是在做功课；这类内容还会被 HR 和同行看到，可能直接带来机会。
3. **一次分析拆多条笔记**：边际成本低，不需要日更跟热点。

### 明确不做
- ❌ 纯 AI 工具实测：大 V 已占满，需要日更，每周 5 小时拼不过全职博主
- ❌ 纯课程项目拆解：太硬核，小红书受众窄，流量天花板低
- ❌ 纯校园日常：零差异化，对简历无加成

## 六、单篇生产 SOP（目标 3–4h / 篇）

1. **定结论（20min）** — 先想清楚这篇要证明什么。**先有结论再取数，不要为了跑数据而跑数据。**
2. **取数（60min）** — Python 爬虫 / 公开数据集 / 自己记录
3. **分析（60min）** — 清洗 + 建模 + 出图，图表统一配色
4. **成图（40min）** — 9 图结构：封面 → 问题 → 方法 → 3–4 张数据图 → 结论 → 互动引导
5. **文案（30min）** — 开头 3 行必须抓人（抛争议结论 / 抛数字）；正文口语；结尾提问引导评论
6. **发布 + 记录（10min）** — 发完立刻进 tracker
7. **48h 后复盘（15min）** — 看数据、记结论

## 七、数据复盘表（tracker.csv）

字段：
```
日期, 标题, 系列, 发布时段, 曝光, 点击率, 阅读, 点赞, 收藏, 评论, 涨粉, 收藏率, 涨粉率, 判定, 下一步动作
```

**判定标准（小红书）**
| 指标 | 合格线 | 说明 |
|---|---|---|
| 点击率 | > 10% | 低于此 → 封面/标题有问题，与内容质量无关 |
| 收藏率 | > 5% | 干货型内容的核心指标 |
| 收藏/点赞 | > 1 | 说明是"有用"而非"好看"，符合定位 |
| 涨粉率（涨粉/阅读） | > 1% | 账号吸引力 |

**判定后的动作**
- 爆（曝光 > 1 万）：48h 内做同主题的续集，把流量吃透
- 平（1000–1 万）：保留，看是哪类选题稳定，加大配比
- 扑（< 1000）：只改封面和标题重发一次；再扑就换选题方向，别死磕

## 九、变现里程碑

| 阶段 | 解锁 | 动作 |
|---|---|---|
| 0–500 粉 | 店铺（0 粉可开）、品牌置换 | **不接广告**，只做内容；可挂免费资料引流 |
| 500 粉 | 广告直发 50–300 元/条 | 只接工具类 / 教育类，别接杂牌（伤权重） |
| 1000 粉 | 蒲公英 200–800 元/条 + 带货佣金 | 主力变现起点；上架资料包（SQL / Python 笔记、简历模板） |
| 5000 粉 | 商单 800–3000 元/条 | 开小课（99–299）；1v1 咨询（简历 / 方向诊断，99–199 次） |
| 1 万粉 | 品牌主动邀约 | 系统课 / 训练营；考虑接长期合作 |

**隐藏收益（可能比钱更重要）**：垂直账号 + 真实传播数据，在投数据分析 / 产品 / 运营实习时，是比水实习更有说服力的经历。

## 十、红线与风险

1. **爬虫合规**：遵守 robots.txt，控制请求频率，不爬个人信息，不做商业用途，数据仅用于统计聚合。
2. **数据必须真实**：不编造、不美化。这个赛道的全部价值建立在"我跑的是真数据"上，糊弄一次就毁号。
3. **不用 AI 批量生成内容**：你的差异化就是真实分析，AI 生成会立刻失去优势。
4. **涉及公司 / 个人一律匿名化**。
5. **每周 5 小时上限**。GPA 是保研命根子，期末周直接停更，不要硬扛。
6. **不买起号课，不签 MCN，不刷量刷粉**（刷粉会打乱账号标签，基本等于废号）。
