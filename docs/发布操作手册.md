### 为什么不能写「若想要开源脚本 请私信咨询」

私信本身是站内功能、「合作请私信」这类写法是允许的。问题出在**"开源脚本"**这四个字：

- 它明示了站外有东西存在
- 加上"私信获取"，就构成一条完整的变相导流链路，
  对应规则里点名的「私信领福利」「完整版不在这」——这类话术系统全部识别
- 而且你会被自己架住：真在私信里发链接，私信同样纳入监管，一样违规；
  不发，就是承诺落空

**新号没有违规缓冲，别用一行简介去赌这个。**

另一个更实际的理由：简介的作用是把人转成**关注**，不是转成**私信**。
「每周三、周日更新」给的是一个关注理由；「私信咨询」给的是一道门槛，
新号阶段只会降低关注率。

### 简介里**绝对不要**出现的东西

小红书《交易导流违规管理细则》把**昵称、头像、背景图、小红书号、个性签名**全部纳入监管，
"发布其他平台链接""图片植入""变形表达"都算违规，处罚从限流到封号。

所以：

- ❌ 不要贴 `github.com/Lebmar/...` —— 属于"发布其他平台链接"
- ❌ 不要写"主页有链接""去 GitHub 找我" —— 属于"暗示引导前往第三方"
- ❌ 不要在图片角落加水印、不要打码露出 —— 属于"图片植入"
- ❌ 不要用 G!thub、谐音、拆字 —— 识别能力很强，属于"变形表达"
- ✅ 想让人找到，就把**小红书号设成 `Lebmar`**。这是平台内的字段，
  不算外链，但懂的人搜 GitHub 同名就能找到你。

**别为了引流冒这个险。** 这个号的第一价值是简历资产（HR 直接看仓库），
不是从平台往 GitHub 导流量。站内留个同名就够。

昵称和头像一旦定了**不要频繁改**，改一次账号标签就要重新积累一次。

## 3. 标题（≤ 20 字，选一个）

**首选**

**备选**

- 58 万条数据训出的模型，换个考场直接不及格

选首选的理由：它对准的是读者的**自我怀疑**（"我那个高分是真的吗"），
备选两条说的还是"我的实验"。前者能让人点进来，后者只能让同行点进来。

## 4. 正文（完整版，直接复制）

```
先说结论：同一个模型、同一份数据，我只换了一种「考法」，
得分从 0.92 掉到 0.27。

不是模型变笨了，是之前那道题太简单。

数据用 UCI Covertype，58 万条真实的森林调查记录，
54 个特征，判断每块地属于 7 种森林类型里的哪一种。
模型是 ExtraTrees，100 棵树，一个不用调参的经典基线。

考法一：随机抽题（课程作业里的默认做法）
把 58 万条随机分成 80% 训练、20% 测试
准确率 0.948，综合得分 0.920
这是可以直接交上去的成绩。

考法二：换个考场
数据自带 4 个地理区域，每次拿 3 块训练、留一整块当测试集
这一块地方，模型从头到尾没见过
四个区域分别是 0.241 / 0.460 / 0.211 / 0.151
平均 0.266，比随机划分低了 71%，最差的一块只剩 0.151

为什么会差这么多
随机划分的时候，训练集和测试集来自同一片区域，
土壤类型、海拔分布几乎一样 —— 相当于在考原题
（看图 8 左边，红点均匀混在灰点里）
换成整块区域，模型面对的是完全陌生的地理条件，
平时背的答案就不管用了。

所以，给你三个自查问题：
① 你的测试集和训练集，是不是同一批来源？
   同一批用户、同一段时间、同一个地方，都算。
② 把测试集换成另一段时间或另一批人，分数会掉多少？
   掉得越多，之前的水分越大。
③ 别只看准确率。7 个类别里只猜中多数类，准确率也可能很好看。

说清楚局限：随机划分不是不能用。它回答的是
「模型能不能拟合这批数据」，回答不了「能不能迁移到新地方」。
两个问题不同，别拿前者的分数去回答后者。

数据是公开数据集，脚本我自己写、结果自己跑，每一篇都真跑。
你的项目掉过多少？评论区报个数，
留言最多的那种数据，我下期拿真实数据跑一遍。
```

### 正文的写法规则（以后每篇都按这个来）

| 规则 | 说明 |
| --- | --- |
| 前 3 行必须出结论 | 小红书没人有耐心往下翻 |
| 一句一行 | 手机上不出现 3 行以上的大段 |
| 数字单独成行 | `平均 0.266` 比塞在句子里好读 |
| 必须写局限性 | 这是专业度的体现，也是差异化的来源 |
| 结尾给具体参与方式 | 不要写"求关注"，要写"报个数" |

## 7. 发布后 0–1 小时：评论区

**第一步：立刻自己发一条置顶评论**

```
补充一个细节：这次的数据自带地理标签，所以我才能切出
「换考场」这个场景。不是所有数据集都有这个条件。
你手头的数据能怎么切？
```

作用：给读者一个具体的参与入口，比"求关注"有效得多。

**第二步：前 60 分钟，每条评论都回**

- 回复里带一个反问，把对话延长（评论互动率影响推荐）
- 遇到质疑不要辩解，给数据。例："你这个结论不成立" → "你觉得哪个部分不成立？我补一组对照跑给你看"
- 不删评论、不回呛

## 9. 首篇的心理预期（这条最重要）

**首篇大概率 200–1500 曝光。这是正常的。**

这个定位（数据科学学生向）本来就不是泛流量赛道，它靠的是**搜索长尾**——
一篇笔记能在搜索里躺 6–12 个月持续带来流量。所以首篇的正确期待不是"爆"，而是：

- 有没有人点进来 → 点击率 > 10% 就说明封面合格
- 有没有人收藏 → 收藏率 > 5% 就说明内容合格

**三个不要：**

1. **不要删了重发** —— 会丢掉初始流量池，重发的那条权重更低
2. **不要买薯条、不要刷量** —— 假数据会污染账号标签，之后推荐全乱
3. **不要因为首篇数据差就换方向** —— 至少发满 10 篇再判断
