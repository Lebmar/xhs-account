# 内容规范

第一条就定死，后面不改。统一的视觉是账号被记住的前提。

所有成图**必须**用 `02-data/scripts/xhs_kit.py` 出，不许手写像素、不许用 matplotlib 默认样式。
上一版（v1）图的问题就出在这里：每页下半部分空一半、字体是系统默认黑体、图表是 matplotlib 原样贴上去——
读起来像大学课件，不像一个账号。

---

## 一、视觉规范

### 画布

- 尺寸固定 **1080 × 1440**（小红书 3:4）
- 左右留白 **88px**
- 正文区固定 **y = 200 → 1268**，页脚线在 **y = 1310**
- **正文区必须填满。** 内容底部留在 1100 以下 = 这页没写完

### 配色（只用两个数据色）

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 底色 | `#FFFFFF` | 纯白。信息流里最干净 |
| 正常数据 | `#15171C` | 墨黑。不做花哨配色 |
| 异常数据 | `#E23E2B` | 朱红。**只用来标"有问题"的那个数** |
| 卡片底 | `#F4F5F7` | 中性卡片 |
| 红色卡片底 | `#FBEDEA` | 结论 / 警告卡片 |
| 正文 | `#414752` | |
| 整句式说明 | `#6B7280` | 不要用更浅的灰，手机上会糊 |
| 标签 / 单位 | `#8E949E` | |
| 页码等装饰 | `#C7CBD2` | |

**不要第三个数据色。** 一页里红色只出现一次，读者才知道该看哪。

### 字体

- 统一 **Noto Sans SC**（可变字体，`02-data/assets/fonts/NotoSansSC-VF.ttf`，本仓库不提交二进制，用 `fetch_fonts.sh` 拉取）
- 标题 Bold / Black，正文 Regular，标签 Medium
- **中文和数字用同一套字体**，靠字重分层级，不靠换字体

### 字号层级

| 层级 | 字号 | 字重 |
| --- | --- | --- |
| 封面主标题 | 84 | Bold |
| 内页标题 | 74 | Bold |
| 关键数字 | 96–158 | Bold / Black |
| 卡片小标题 | 38–40 | Bold |
| 正文 | 32–36 | Regular |
| 标签 / 脚注 | 28–32 | Medium |

### 卡片排版规范（v3 起强制执行）

**卡片高度一律不许手写。** 用 `card_fit()`，由它量内容、画底、再把内容垂直居中。
手写坐标的后果就是「上留白 44、下留白 6」——2026-10-09 那一版就是这么废掉的。

- 内边距上限统一：左右 `CARD_PAD_X = 48`，上下至少 `CARD_PAD_Y = 44`
- **上下留白必须相等**：内容整体在卡片里垂直居中，不是顶部对齐
- 卡内文字层级：小标题 38 Bold / 说明 32–36 Regular，两者间距 20–22
- 大数字卡片：数字独占一行（104–118 Bold），注释另起一行左对齐；数字与注释间距 28–30
  **禁止**把注释挂在数字右侧——字宽不可控，一定会顶到卡片边缘
- 卡片内单块文本优先用 `\n` 手动断行，保证两行长度接近；不要让算法留下一行只有 2 个字的孤儿行

### 中文排版避头尾（已内建在 `wrap()`）

- 标点（`，。、；：？！）」』` 等）**不允许出现在行首**——遇到就把上一行末尾的字一起带下来
- 开引号 / 开括号（`「『（《` 等）**不允许出现在行尾**
- 任何一行的宽度**不得超出容器**。这是 v2 的真实 bug：避头规则把标点硬塞回本行，
  导致文字右侧贴死卡片边缘（右边距 0）

### 出图自检（每次出图必须跑，不通过不许发）

脚本结尾会打印三行：

1. 每页内容底部 y，超过 **1268** 即报「溢出」
2. **文字宽度检查**——任何一行超过容器宽度都会被列出来
3. 核心数据值

### 每页固定元素

1. 左上：红色竖条 + 栏目名（34 Medium）
2. 左下：`跑个数看看`；右下：页码 `n/9`

## 二、9 图结构

不要按"图表 1、图表 2"排。**按叙事线排**，每张图只干一件事：

| 位置 | 职责 | 硬要求 |
| --- | --- | --- |
| 1 | 封面 | 钩子 + 一个数字。说清"这跟你有关系" |
| 2 | 先说结论 | 答案前置。小红书没人有耐心翻到第 8 张 |
| 3 | **这跟你有什么关系** | **必须有这一页。** 缺了它，读者看完只会觉得"哦，好厉害"，然后划走 |
| 4 | 方法与数据 | 建立可信度，一句话带过，别展开 |
| 5–6 | 对照 A / 对照 B | 一页只放一组数，让读者自己看出差距 |
| 7 | 对比 | 一张图把差距钉死 |
| 8 | 原因 | 用图讲机制，不要用术语 |
| 9 | 行动 + 互动 | 给出可带走的东西（自查清单 / 方法），再抛问题 |

**图表要求**：全部自己画。标题 + 单位 + 数据来源脚注。不截图别人的图。

**术语红线**：图上的字，按"完全不懂这个领域的人能不能读懂"来写。
写不进去的术语，换成一句人话；换不掉的，删掉。

## 三、文案模板

### 标题（二选一）

- 数字型：`58 万条数据训出的模型，换个考场直接不及格`
- 反常识型：`你的 94% 准确率，可能只是在背答案`

标题里必须有一个**具体的数字**或一个**能被质疑的判断**。

### 正文开头（前 3 行必须抓人）

```
先说结论：______。
我跑了 ______ 条数据，脚本是自己写的，结果也是自己跑的。
```

### 正文结构

1. 结论先行
2. 数据从哪来（一句话）
3. 3–5 个发现，每个配一张图
4. 局限性说明（**必须写**，这是专业度的体现）
5. 互动问题

### 结尾固定句式

```
数据是公开数据集，脚本我自己写、结果自己跑，每一篇都真跑。
想看我实测什么，评论区告诉我。
```

### 合规红线：不得站外导流

小红书《交易导流违规管理细则》把**昵称、头像、背景图、小红书号、个性签名、笔记、
图片、评论、群聊、私信**全部纳入监管。"发布其他平台链接""图片植入""变形表达"
"暗示引导前往第三方"都算违规，处罚从限流、扣分到封号。

因此**成图与文案中一律不得出现**：

- ❌ 任何平台名 + 链接（GitHub、个人博客、公众号…）
- ❌ "主页有链接""去 XX 找我""平台不让说"
- ❌ 图片角落水印、打码露出、截图里带域名
- ❌ 谐音、拆字、特殊符号替代

**替代做法**：小红书号设成与 GitHub 用户名同名（`Lebmar`）。
这是平台内字段、不算外链，想找的人搜得到。

**别为了引流冒这个险。** 仓库的第一用途是给 HR 看的作品集（简历里直接附链接），
不是从小红书导流——两边各司其职。

## 四、发布流程

| 步骤 | 内容 | 动作 |
| --- | --- | --- |
| 定结论 | 20min | 先想清楚要证明什么，**先有结论再取数** |
| 取数 | 60min | Python 爬虫 / 公开数据集 / 自己记录 |
| 分析 | 60min | 清洗 + 建模 + 出图数据落 `02-data/results/` |
| 成图 | 40min | 调 `xhs_kit.py` 出 9 图，**跑自检直到无溢出** |
| 文案 | 30min | 按模板填充 |
| 发布 | 10min | 周日 / 周三 20:00–22:00 |
| 记录 | 5min | 立刻写进 `04-tracker.csv` |
| 复盘 | 15min | 发布 48h 后进行 |

## 五、数据判定标准

| 指标 | 合格线 | 含义 |
| --- | --- | --- |
| 点击率 | > 10% | 低 → 封面标题问题，与内容质量无关 |
| 收藏率 | > 5% | 干货型内容核心指标 |
| 收藏 / 点赞 | > 1 | "有用"而非"好看"，符合定位 |
| 涨粉率 | > 1% | 账号吸引力 |

| 判定 | 标准 | 动作 |
| --- | --- | --- |
| 爆 | 曝光 > 10000 | 48h 内出同主题续集，吃透流量 |
| 平 | 1000–10000 | 保留，识别稳定选题类型，加大配比 |
| 扑 | < 1000 | 改封面标题重发一次；再扑就换选题方向 |

## 六、红线

1. 数据必须真实，不编造、不美化
2. 不用 AI 批量生成内容（真实分析是本账号的唯一壁垒）
3. 涉及公司 / 个人一律匿名化
4. 每周投入 ≤ 5 小时，期末周直接停更
5. 不买起号课、不签 MCN、不刷量刷粉

## 附：v2 → v3 的修正记录（2026-10-09）

用户反馈「卡片里的文字排布不好」，四张卡片逐一排查：

| 病症 | 根因 | 修正 |
| --- | --- | --- |
| 118px 大数字与右侧注释基线不齐，整块偏上 | 大数字和注释是两段独立硬编码坐标 | 数字独占一行，注释左对齐另起一行，间距 28 |
| 「在课堂上…」卡片上留白 44、下留白只有 6 | 卡片高度和文字位置都是手写的 | 新增 `card_fit()`，自动高度 + 垂直居中 |
| 句号「。」被甩到单独一行 | `wrap()` 只按宽度断行，没有避头规则 | 实现中文避头尾 |
| 「数据跑一遍。」溢出卡片底边 | 内容 206px > 卡片 196px | 同上，由 `card_fit()` 从根上消除 |
| **文字宽 828 > 容器 808，右侧贴死卡片边缘** | **避头规则把标点硬塞回本行，本行随之超宽** | **改成"把上一行末尾的字一起带下来"，并加宽度自检** |
| 点阵图在色块里没居中，下方空一条 | `dot_field()` 从左上角开始铺，余数全丢在右下 | 点阵整体居中 |
| 条形图数值顶到安全边距 | 右侧数值区写死 190px | 按实际文字量计算 |

**新增原语**（`xhs_kit.py`）：`card_fit()` / `points_block()` / `points_height()` /
`text_height()` / `fit_size()` / `stat_big()`，以及出图时的宽度自检 `AUDIT`。
