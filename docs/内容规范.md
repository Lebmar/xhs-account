# 内容规范

第一条就定死，后面不改。统一的视觉是账号被记住的前提。

---

## 一、视觉规范

### 配色（固定两色，所有图表沿用）
| 用途 | 色值 |
| --- | --- |
| 底色 | `#E6F1FB` |
| 主色（强调、折线、关键数字） | `#185FA5` |
| 辅助色（次要系列） | `#85B7EB` |
| 对比色（对比组、负面数据） | `#D85A30` |
| 正文文字 | `#2C2C2A` |
| 次要文字 | `#5F5E5A` |

### 字体
- 封面标题：思源黑体 Bold / 阿里巴巴普惠体 Bold
- 正文图表：系统默认无衬线
- 一屏内字体不超过 2 种

### 封面模板（固定，所有笔记复用）
1. 顶部：系列标签（如「实习实测 01」）
2. 中部：大字标题，**最多 14 个字**，要带一个数字或争议点
3. 底部：一个关键数字，字号最大，视觉锤
4. 右下角：固定署名「跑个数看看」

---

## 二、9 图结构

每篇笔记固定 9 张图，顺序不改：

| 位置 | 内容 | 要求 |
| --- | --- | --- |
| 1 | 封面 | 按上方模板 |
| 2 | 提出问题 | 一句话说清要回答什么，带争议感 |
| 3 | 数据从哪来 | 样本量 + 来源 + 时间范围，建立可信度 |
| 4–7 | 数据图 | 每张图只讲一件事，配一句结论 |
| 8 | 最终结论 | 3 条以内，加粗关键句 |
| 9 | 互动引导 | 抛一个问题，引导评论 |

**图表要求**：每张图必须有标题 + 坐标轴标注 + 数据来源脚注。不截图别人的图，全部自己出。

## 三、文案模板

### 标题（二选一）
- 数字型：`爬了 10000 条笔记，爆款标题只有这 3 种`
- 反常识型：`成绩好不好，和家庭作业时间基本无关`

### 正文开头（前 3 行必须抓人）
```
先说结论：______。
我跑了 ______ 条数据，过程和代码都放在评论区。
```

### 正文结构
1. 结论先行
2. 数据从哪来（一句话）
3. 3–5 个发现，每个配一张图
4. 局限性说明（**必须写**，这是专业度的体现）
5. 互动问题

### 结尾固定句式
```
数据来源已标注，代码开源在 GitHub（主页链接）。
想看我实测什么，评论区告诉我。
```

## 四、发布流程

| 步骤 | 时间 | 动作 |
| --- | --- | --- |
| 定结论 | 20min | 先想清楚要证明什么，**先有结论再取数** |
| 取数 | 60min | Python 爬虫 / 公开数据集 / 自己记录 |
| 分析 | 60min | 清洗 + 建模 + 出图 |
| 成图 | 40min | 按 9 图结构产出 |
| 文案 | 30min | 按模板填充 |
| 发布 | 10min | 周日 / 周三 20:00–22:00 |
| 记录 | 5min | 立刻写进 `04-tracker.csv` |
| 复盘 | 15min | 发布 48h 后进行 |

## 五、数据判定标准

| 指标 | 合格线 | 含义 |
| --- | --- | --- |
| 点击率 | > 10% | 低 → 封面标题问题，与内容质量无关 |
| 收藏率 | > 5% | 干货型内容核心指标 |
| 收藏 / 点赞 | > 1 | "有用"而非"好看"，符合定位 |
| 涨粉率 | > 1% | 账号吸引力 |

| 判定 | 标准 | 动作 |
| --- | --- | --- |
| 爆 | 曝光 > 10000 | 48h 内出同主题续集，吃透流量 |
| 平 | 1000–10000 | 保留，识别稳定选题类型，加大配比 |
| 扑 | < 1000 | 改封面标题重发一次；再扑就换选题方向 |

---

## 六、红线

1. 数据必须真实，不编造、不美化
2. 不用 AI 批量生成内容（真实分析是本账号的唯一壁垒）
3. 涉及公司 / 个人一律匿名化
4. 每周投入 ≤ 5 小时，期末周直接停更
5. 不买起号课、不签 MCN、不刷量刷粉
